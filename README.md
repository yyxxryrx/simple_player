# Simple Player

> This is a practice project

Make a simple video player

## Usage

```bash
simple_player path/to/video.mp4
```

## Build with `Xmake`

Require `c3c`, `odin` and `xmake`

### Build Release

```bash
xmake f -m release
xmake build
```

### Build Debug

```bash
xmake f -m debug
xmake build
```

## Build with `c3c` and `winch`

Require `vcpkg`, `c3c` and `winch`

```bash
winch run c3c build
```
