# Simple Player

> This is a practice project

Make a simple video player

## Usage

```bash
simple_player path/to/video.mp4
```

## Build

Require `c3c` and `xmake`

### Build Release

```bash
xmake f -m release
xmake build
```

### Build Debug

```bash
xmake f -m debug
xmake build
```
